# Details Manager - CRUD App

A simple web application built with Python and Flask that allows users to manage personal details.

## Features
- Add name and age details
- View all details in a clean table
- Update existing details
- Delete details

## Technologies Used
- Python
- Flask
- SQL (SQLite)
- HTML/CSS
- Flask-Migrate

## How to Run
1. Clone this repository
2. Create a virtual environment `python -m venv venv`
3. Activate it `venv\Scripts\activate`
4. Install dependencies `pip install flask flask-sqlalchemy flask-migrate`
5. Run the app `python app.py`
6. Open browser and go to `http://127.0.0.1:5000`
